## Boundaries and implemented limits

The local archive holds at most eight passports, eight retained raw runs, twelve public notes per agent, twenty-four plan artifacts and sixteen handoffs, within 1.35 MB. Receipts referenced as artifact/memory provenance cannot be silently discarded. Export before adding a dependent run that cannot fit. Profiles retain their existing 3 MB import boundary. Notes and identity are editable declarations; arbitrary operator text cannot be proven free of outside knowledge. The host never derives notes from hidden state. Recorded holdout/transfer notes and artifacts cannot become automatic career context.

V8 worlds admit bounded public notes and verified world plans. Admitted plan goals/steps/fallbacks enter the bounded public notebook, and the actual receipt controller declares notebook context. The V7 career adapters accept fresh inputs only; their original independent episode notebooks and optional explicit local-model connection remain in the Garage. The Locker offers public baseline, deterministic mock and human control; it never auto-connects a imported Ollama setting. Portable artifacts contain no code and never grant action or state authority. At V9, reserved voice/vehicle/media/license fields remain empty and confer no capabilities. World outcomes can include team actions and are not attributed as universal individual skills.
